Interview Chatbot

An AI-powered chatbot built using Streamlit and the Gemini API that simulates an interview environment and provides feedback based on user responses.

Features
Interactive chat interface
Simulated interview questions
AI-generated feedback on responses
Session-based conversation flow
Tech Stack
Python
Streamlit
Google Gemini API
Setup
Clone the repository

Create a .streamlit/secrets.toml file and add your API key:

GEMINI_API_KEY = "your_api_key_here"
Install dependencies

Run the app:

streamlit run app.py
